## 🧑‍💻 About Me

<img align="right" width="400" src="https://user-images.githubusercontent.com/74038190/212749447-bfb7e725-6987-49d9-ae85-2015e3e7cc41.gif" alt="coding"/>

I'm an **AI Engineer** and a curious builder who loves shipping useful software.

I work across **AI, modern web stacks, and systems-level tools**, building products that are fast, clear, and honest for real users.

- 🎓 **Mentor @ Scala Center**, guiding GSoC contributors on LLM tooling & observability after completing GSoC '25
- ☁️ **CNCF Contributor**, actively contributing to Cloud Native ecosystem projects
- 🔬 **GSoC '25 Alumni**, built tracing & observability features for LLM4S in the Scala ecosystem
- 📄 **IEEE Published Author**, presented at IEEE SPACE 2024 on UAV-based crop health monitoring using AI/ML
- 🏗️ Currently building with **Generative AI, NLP, and Full Stack**
- 🦀 Growing my skills in **Rust** and **Go** for performant backends
- 🌐 Previously interned as a **Cloud Engineer**, automated ops for 9,000+ servers
- 💡 I believe in: **craft, impact, and open source**
